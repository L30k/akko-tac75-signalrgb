# Contributing

Keep changes scoped and include tests. Preserve the identity/capability checks, fixed 5 FPS default, explicit activation and release behavior. Do not silently add flash-persistent commands to the streaming path.

For a new PCB/firmware revision, provide evidence for identity, LED ordering, memory layout and recovery. Never claim compatibility from VID/PID alone. Emulator success is not hardware qualification.

Use English for code/UI and the main README. Keep Portuguese installation instructions aligned. For a report, include reproducible steps, software versions and sanitized console errors. Remove serial numbers, local account paths and USB location paths.
