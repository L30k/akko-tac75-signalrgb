# v0.4.0-rc.1 — Experimental prerelease

**Still under development and testing. Use entirely at your own risk. No warranty or guaranteed recovery. Read [DISCLAIMER.md](../docs/DISCLAIMER.md) before downloading, building or installing.**

This is a private review release for L30k. It has not been qualified for general use. The maintainer and contributors accept no liability to the extent permitted by applicable law. No repair, replacement or reimbursement is promised.

## Contents

- SignalRGB plugin: direct per-key USB lighting, 83 registered key positions, fixed 5 FPS, English interface.
- Windows Firmware Manager: redesigned English interface, manual install/restore and RAM lighting test. No bridge service required.
- Firmware tools: reproducible patch for one exact ID2782/V502 base. Firmware image is unchanged from the owner's working RAM1 test.
- Source tests and separate installation, protocol, architecture, validation and recovery documents.

## Downloads

The source archive excludes proprietary vendor images, personal records and third-party product images. The Windows manager executable includes the verified firmware pair for operation; it is prepared locally for the owner's review and is not attached to a GitHub release automatically. The base-download helper lets developers obtain and verify their own official image.

No new firmware write is needed on the owner's already modified keyboard. This release does not turn the stock firmware into RAM streaming without the separate experimental patch.

## Known limits

One owner test unit. No proven recovery from an application hang. Peak stack, suspend/resume, simultaneous vendor-app access, exhaustive LED mapping and long-term operation remain unqualified. A loaded direct plugin is not evidence of all these properties.
